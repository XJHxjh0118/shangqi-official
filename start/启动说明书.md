# 启动说明书（Windows）

适合：拿到本模板后，在自己电脑上打开官网和管理后台。

更完整的项目介绍见仓库根目录 [README.md](../README.md)。

---

## 你需要有哪些文件夹

保持下面结构（`一键启动.bat` 在 `start/` 目录内）：

```
official-demo/                 ← 项目根目录
  ├─ README.md
  ├─ backstage-management/     ← 后台 + 接口
  ├─ official-website/         ← 官网门户
  └─ start/
       ├─ 一键启动.bat
       ├─ 一键停止.bat
       └─ 启动说明书.md        ← 本文件
```

---

## 第一次使用前：只装一次软件

### 1. 安装 Node.js

1. 打开官网：https://nodejs.org  
2. 下载并安装 **LTS（长期支持版）**  
3. 一路下一步，使用默认选项  
4. 安装结束后，**重启电脑**（推荐）

### 2. 验证是否装好

1. 按键盘 `Win + R`，输入 `cmd`，回车  
2. 输入下面两行，每行回车一次：

```bat
node -v
npm -v
```

能显示版本号（例如 `v22.x.x`）就说明装好了。  
如果提示“不是内部或外部命令”，说明 Node 没装好或没重启，请重装后再试。

> `pnpm` 不用提前装：`一键启动.bat` 发现没有时会自动帮你装。

## 日常怎么启动（推荐）

1. 双击 **`start/一键启动.bat`**  
2. 第一次会自动安装依赖、初始化数据库，可能要 **5～15 分钟**，请耐心等，不要关窗口  
3. 成功后会自动弹出两个黑色窗口，并尝试打开浏览器  
4. 记住这些地址：

| 名称 | 地址 | 用途 |
|------|------|------|
| 官网门户 | http://localhost:3000 | 给访客看的官网 |
| 管理后台 | http://localhost:8848 | 登录后改产品、处理咨询 |
| 接口文档 | http://127.0.0.1:3001/car/docs | 可选，给技术人员看 |

### 默认登录账号（管理后台）

| 角色 | 用户名 | 密码 |
|------|--------|------|
| 管理员 | `admin` | `admin123` |
| 编辑 | `editor` | `editor123` |

## 怎么停止

任选一种：

1. 双击 **`start/一键停止.bat`**  
2. 或在两个黑色窗口里分别按 `Ctrl + C`，再关闭窗口  

**黑色窗口关掉后，网站就打不开了。** 需要访问时再双击「一键启动.bat」。

---

## 使用时注意

1. **两个黑色窗口要一直开着**，最小化可以，不要叉掉。  
2. 必须先有后台，再有官网；一键脚本已经按这个顺序启动。  
3. 电脑休眠、断网一般不影响本机访问（这是本地服务）。  
4. 这是在你自己电脑上运行，**别人在外网打不开**；要公网访问需要服务器或云托管。

## 常见问题

### 1. 双击后提示找不到 Node.js

→ 按上面「安装 Node.js」重做，并重启电脑。

### 2. 窗口里出现 `'pm'`、`'ho'` 等乱码命令

→ 通常是 **一键启动.bat 编码/换行损坏**（应用更新后请重新复制 `start` 目录）。  
→ 先运行 **start\一键停止.bat**，再重新双击 **一键启动.bat**。  
→ 若提示 pnpm 不可用，在 cmd 里执行一次：`corepack enable`，然后重试。

### 3. 官网能开，但是没有产品 / 一直转圈

→ 后台没起来。看有没有标题类似「运营后台」的黑窗口；没有就再运行一次「一键启动.bat」。  
→ 或浏览器先打开 http://127.0.0.1:3001/car/docs ，打不开说明后台失败。

### 4. 管理后台打不开 http://localhost:8848

→ 等黑窗口里出现启动完成相关字样再刷新。  
→ 首次安装依赖很慢，请再等几分钟。

### 5. 提示端口被占用（EADDRINUSE / port already）

→ 先运行「一键停止.bat」，再重新「一键启动.bat」。  
→ 仍不行：重启电脑后再试。

### 6. 杀毒软件拦截 / 窗口一闪就关

→ 把项目文件夹加入杀毒软件信任区。  
→ 用「在终端中运行」或右键「以管理员身份运行」再试一次。

### 7. 第一次特别慢，像卡住了

→ 正在下载依赖，需要网络。尽量用稳定网络，不要中断。  
→ 第二次启动会快很多。

### 8. 提示找不到文件夹

`一键启动.bat` 需要位于 `start/` 下，且上一级目录中存在 `backstage-management` 与 `official-website`。

### 9. Prisma 报 EPERM / query_engine-windows.dll.node

→ 说明有旧的 Node 进程占用了数据库引擎文件。  
→ 先运行 **start\一键停止.bat**，关闭所有相关黑色窗口，再重新 **一键启动.bat**。  
→ 仍失败：任务管理器结束多余的 `node.exe`，或重启电脑后再试。

## 不想用一键脚本时（手动）

### 启动后台

进入 `backstage-management`，双击 `start.bat`。

### 启动官网

在 `official-website` 文件夹打开命令行：

```bat
npm install
npm run dev
```

然后浏览器打开 http://localhost:3000 。

更细的技术说明见：

- 根目录 `README.md`
- `backstage-management/README.md`
- `official-website/README.md`

## 一句话总结

装好 Node → 双击 **start/一键启动.bat** → 打开  
http://localhost:3000（官网）和 http://localhost:8848（后台，账号 admin / admin123） → 用完点 **一键停止.bat**。
